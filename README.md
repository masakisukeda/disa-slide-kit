# DiSA スライドキット

HTMLで提案スライドを作るためのテンプレートとレイアウト部品集です。
一般社団法人ディレクションサポート協会（DiSA）が実務で使っているものから、
**自社向けにカスタマイズするのに必要な最低限**を取り出して公開しています。

PowerPoint も Google スライドも使いません。**HTMLファイル1枚がスライド1式**です。
ブラウザで開けばそのまま投影でき、印刷ダイアログからPDFにも書き出せます。

## 何が入っているか

| ファイル | 中身 |
| --- | --- |
| `template.html` | 新規作成の起点。1ページ=1スライドの構造、ナビゲーション、印刷レイアウト込みで6枚ぶん |
| `patterns.html` | レイアウト部品のカタログ。比較テーブル、Before/Afterフロー、4象限、ロードマップ、タイムライン、目次、中表紙、数値ハイライト、人物紹介など30パターン |
| `STYLE_GUIDE.md` | 作成ルール。構成の決め方、配色、文字サイズ、PDF書き出しの手順と失敗例まで |
| `logo.svg` | 差し替え用のプレースホルダロゴ |
| `profile-photo.svg` | 差し替え用のプレースホルダ顔写真 |

## 使い方

1. このリポジトリをダウンロードする（`Code` → `Download ZIP`、または `git clone`）
2. `template.html` を案件用のフォルダへコピーして `index.html` にリネームする
3. `logo.svg` と `profile-photo.svg` を同じフォルダに置き、**自社のものに差し替える**
4. ブラウザで `index.html` を開く。矢印キーでスライドが送れる
5. 部品が要るときは `patterns.html` をブラウザで開き、使いたいスライドの
   HTMLと対応するCSSブロックを `index.html` へコピーする

### 色を変える

**表紙の `<section>` に1箇所書くだけです。** CSSは触りません。

```html
<section class="slide slide-dark slide-lead active" id="slide-1" data-accent="#0b2e4f">
```

濃淡やホバー色などの派生色は、末尾のスクリプトが自動で計算します。
`data-accent` を書かなければ、既定のネオンイエローのままです。

制作中は表紙の右下にカラーピッカーが出るので、そこで色を試してから確定できます。
**ピッカーで選んだ色はファイルに保存されません。** 決まったら `data-accent` に書いてください。
納品前には、`制作用` とコメントで囲ったピッカーの3ブロック（CSS・HTML・script）を削除します。

### 差し替えるところ

置換すればいいのは、この5つです。

- `logo.svg` — 自社のロゴ（横長・およそ 6.3 : 1）
- `profile-photo.svg` — 担当者の写真（正方形）
- `〇〇株式会社` — フッターと会社概要面の社名
- `〇〇 太郎` ほかプロフィール面のダミー — 担当者の情報
- `data-accent` — アクセントカラー

## PDFにする

Chrome の印刷ダイアログから「PDFに保存」を選びます。
用紙は**横向き・余白なし・背景のグラフィックON**。詳しい手順と、
1枚目が白紙になるなどの失敗例は `STYLE_GUIDE.md` の6章にまとめてあります。

## 設計の考え方

細かいルールは `STYLE_GUIDE.md` にありますが、芯は3つです。

- **アクセントカラーは1色。** 強調には予算があります。全部を目立たせると、何も目立ちません
- **フォントは2種類まで。** 欧文・数字は `Inter`、和文は `Noto Sans JP`
- **1枚に1つの主張。** タイトルだけを上から通し読みして話が1本につながるなら、その資料は伝わります
